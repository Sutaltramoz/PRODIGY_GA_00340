# Task 03: Text Generation with Markov Chains

This project is part of my Generative AI internship at Prodigy InfoTech.

## Objective
Implement a simple text generation algorithm using Markov chains to predict the probability of a word based on the previous word(s).

## How it Works
The model uses a Python dictionary-based Markov Chain to analyze input text and generate coherent sentences based on word frequency and transition patterns.# PRODIGY_GA_00340
